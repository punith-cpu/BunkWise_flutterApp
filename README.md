# BunkWise AI

BunkWise AI is a smart, offline-first college attendance management and bunk decision assistant built with Flutter.

The application helps students track subject-wise attendance, manage weekly timetables, record holidays and exams, calculate safe bunk limits, and receive recovery recommendations when attendance falls below the required percentage.

## Key Features

- Subject-wise attendance tracking
- Smart bunk safety recommendations
- Attendance recovery planning
- Weekly timetable management
- Flexible time-slot selection
- Timetable overrides and extra classes
- Holiday, exam, and cancelled-day management
- Danger zone attendance indicator
- Subject priority management
- Local notifications for attendance risks
- Offline SQLite storage
- Modern Android-focused Flutter UI

## Technology Stack

- Flutter
- Dart
- Riverpod
- SQLite with `sqflite`
- SharedPreferences
- Flutter Local Notifications

BunkWise AI is designed to make attendance planning simple, practical, and student-friendly.
